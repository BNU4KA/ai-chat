# План реализации

Каждый этап завершать работающим результатом и коротким отчётом: что сделано, как проверено,
что требует credentials или внешнего решения. Не начинать с полной отрисовки всех экранов.

## Этап 0. Проверка интеграций
- Зафиксировать совместимые версии и минимальные поддерживаемые OS/browser.
- Проверить Google SSO в development builds и web; описать callback configuration.
- Доказать OpenRouter streaming + tool call → result → final response.
- Проверить Gmail/Calendar OAuth на тестовом Google-проекте, зафиксировать scopes и verification.
- Принять короткие архитектурные решения по очереди, search provider и hosting.
Готово: воспроизводимый сквозной прототип и список подтверждённых внешних ограничений.

## Этап 1. Основа
- pnpm workspace, клиент, API, worker; scripts dev/typecheck/lint/test.
- Supabase migrations, auth, профиль, RLS и закрытые credentials tables.
- Env validation, .env.example, общие контракты и API authentication.
Готово: один аккаунт на трёх платформах, тесты межпользовательской изоляции.

## Этап 2. Вертикальный чат
- Onboarding Google → OpenRouter key → модель → чат.
- Шифрование ключа, каталог моделей, сообщения и серверный run.
- Поток событий, восстановление cursor и синхронизация второго устройства.
Готово: настоящий ответ модели, сохранение истории, корректные stop/errors.

## Этап 3. Надёжный агент
- Durable queue, leases, state machine, persisted events, лимиты.
- Registry tools, валидация, авторизация, approvals, idempotency и cancel.
- Crash/reconnect и неопределённый результат side effect.
Готово: тестовый инструмент проходит полный цикл, сбой worker не теряет задачу.

## Этап 4. Интернет и файлы
- Search adapter, безопасное чтение страниц и источники.
- Private uploads, extraction, chunks, ссылки на документ/страницу.
- Лимиты, плохие файлы, cross-user access и prompt injection проверки.
Готово: ответы по актуальному поиску и пользовательским документам с источниками.

## Этап 5. Gmail и Calendar
- Отдельные подключения, refresh/revoke/disconnect.
- Поиск и чтение, черновики, календарь, free/busy.
- Подтверждённая отправка и создание/изменение события.
Готово: тестовые сценарии, безопасные повторы и прозрачная обработка OAuth ошибок.

## Этап 6. UX и подготовка поставки
- Адаптивность, темы, accessibility, настройки и удаление данных.
- E2E web, smoke iOS/Android, usage и понятные состояния инструмента.
- Инструкции запуска/деплоя, monitoring, backup/restore, перечень затрат.
- Перед App Store: проверить login requirements и необходимую альтернативу Google.
Готово: проверяемые сборки и чеклист с честным статусом каждой интеграции.
