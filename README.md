# AI Agent Chat

Персональный чат с ИИ-агентами через пользовательский OpenRouter API-ключ.
Платформы: iOS, Android, Web. Вход и регистрация: Google SSO.
История и задачи синхронизируются между устройствами; агенты выполняются на сервере.

## Задание агенту

1. Прочитать [полное техническое задание](docs/AGENT_TASK.md).
2. Следовать [плану реализации](docs/IMPLEMENTATION_PLAN.md).
3. Начать с проверки интеграций и работающего сквозного сценария, затем расширять продукт.

Репозиторий содержит задание для разработки. Приложение ещё не реализовано.
Рабочее название `AI Agent Chat` можно заменить перед публикацией.

## Базовая архитектура

- `apps/client`: Expo, React Native, React Native Web, Expo Router, TypeScript.
- `apps/api`: Fastify, TypeScript; пользовательский API и поток событий.
- `apps/worker`: выполнение агентов и интеграций вне жизненного цикла клиента.
- `packages/contracts`: API-контракты, схемы инструментов и событий.
- `packages/agent-runtime`: цикл агента, политики, лимиты.
- `packages/integrations`: OpenRouter, поиск, файлы, Gmail, Google Calendar.
- `supabase`: миграции, RLS, Storage policies.

Структура — целевая; создавать пакеты по мере появления работающего кода.
